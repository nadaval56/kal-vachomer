# סגולת הקל וחומר

אתר סטטי סביב סגולת רפואת החולה של הבן איש חי — **לשון חכמים חלק ב, סימן טז**.

שני מצבים נפרדים:

| | |
|---|---|
| **`/`** — *להתפלל* | חמשת קטעי הקל וחומר והבקשה, בנוסח לשון חכמים. עמוד אחד, גלילה אחת, בלי הערות שוליים. |
| **`/study/`** — *להבין* | שרשרת המסירה, טבלת י״ג מול י״ג, פירוק הלוגיקה של כל קטע, וההשמטה. |

---

## איך זה בנוי

```
data/*.json        ← כל התוכן. מקור אמת יחיד.
scripts/build.mjs  ← מרנדר ממנו את index.html ו־study/index.html
index.html         ← נוצר. לא לערוך ידנית.
study/index.html   ← נוצר. לא לערוך ידנית.
assets/            ← style.css, app.js, גופנים
```

**לשנות תוכן:** לערוך את `data/*.json`, ואז

```bash
node scripts/build.mjs
```

ה־HTML הבנוי מקומט לריפו כדי ש־GitHub Pages יגיש קבצים סטטיים בלי שום `fetch`
בזמן ריצה. ה־Action ב־`.github/workflows/pages.yml` בונה מחדש ונכשל אם ה־HTML
שבריפו אינו תואם ל־JSON.

### למה build ולא fetch מהדפדפן

המפרט מתאר `app.js` שקורא JSON. העדפתי רינדור בזמן build: הטקסט המנוקד מגיע
בגוף ה־HTML, כך שהוא נקרא גם בלי JavaScript, נדפס נכון, ואין הבזק של עמוד ריק
ליד מיטה בשלוש לפנות בוקר. `app.js` נשאר רק להתנהגות — גודל גופן, מצב לילה,
שיבוץ השם.

## תוכן

| קובץ | מה יש בו |
|---|---|
| `data/texts.json` | חמשת הקטעים והבקשה — **נוסח לשון חכמים כפי שנמסר**, בלי עריכה. |
| `data/study.json` | שרשרת המסירה, פירוק הקל וחומר, ההשמטה, קולופון. |
| `data/middot.json` | טבלת י״ג מידות הדרשה מול י״ג מידות הרחמים. |
| `data/commentary.json` | נמשך מספריא ב־build. ריק כברירת מחדל. |

### מה עדיין חסר, ומסומן ככזה באתר

- **הציטוט המלא מבני יששכר** (מאמרי חודש אלול ב, ז). מוצגת תמצית בלשוננו,
  מסומנת במפורש כתמצית ולא כציטוט.
- **עשר השורות התחתונות בטבלת י״ג מול י״ג.** מתועדות רק שלוש —
  קל וחומר↔אֵל, גזירה שווה↔רחום, בנין אב↔וחנון. הבני יששכר סוגר ב״וכן באינך״
  ומפנה ל״ובמ״א הארכתי בעניינים הללו ברחב ידים״; אותו מקום טרם אותר.
  **לא הושלמו שורות מסברה** — שורה בלי מראה מקום מאומת נשארת ריקה ומסומנת
  בהצללה אלכסונית.

## ספריא

`scripts/fetch-sefaria.mjs` בונה את שכבת העיון: ביאור שטיינזלץ, רש״י,
ברטנורא, תוספות יום טוב, רמב״ם על המשנה, תוספות, מהרש״א, והפסוקים.
נשמר ל-`data/commentary.json`; **הדפדפן לעולם אינו פונה לספריא.**

לכל קטע מוגדרים עוגני איתור. הסקריפט מושך את הדף, מאתר את הקטע שבו
נמצא הלימוד שלנו, ומביא פירושים על אותו קטע בלבד — לא על הדף כולו.
פירוש שמפנה למסכת אחרת נדחה. טעמי המקרא מוסרים כדי שיתאימו לגופן שבאתר,
ומראי המקום מומרים לעברית.

באתר זה מופיע כ״להרחיב״ בסוף כל קטע, וגם בלחיצה על שם המקור שבכותרת.
כל מפרש נפתח בנפרד; ביאור שטיינזלץ פתוח כברירת מחדל.

```bash
node scripts/fetch-sefaria.mjs --dry --verbose   # בדיקה בלי כתיבה
```

הרענון רץ ב-`.github/workflows/sefaria.yml` (חודשי, או ידנית ב-Actions).
אם הבקשות נכשלות הסקריפט יוצא בהצלחה ואינו דורס את הקובץ הקיים,
והשכבה פשוט אינה מוצגת. הטקסט הראשי אינו מוחלף בנוסח ספריא לעולם.

## תמונת השיתוף

`assets/og.png` היא מה שנראה בתצוגה המקדימה בוואטסאפ ובכל שיתוף אחר.
היא נוצרת מ-`scripts/og-card.html`, שמשתמש באותם גופנים וצבעים של האתר,
ולכן היא נראית כמוהו ולא כמו נכס שנוצר בנפרד.

```bash
npm i -D playwright
node scripts/make-og.mjs
```

ה-PNG מקומט לריפו, כך שהבנייה הרגילה אינה תלויה ב-playwright.
כתובת התמונה נושאת חתימת תוכן, כדי שרשתות לא יחזיקו גרסה ישנה.

## עיצוב

- גופן יחיד: **Assistant** (SIL OFL), מוגש מהריפו. יש בו את כל סימני הניקוד
  ומיקום GPOS נכון.
- **טעמי המקרא הוסרו מן הטקסט** לפי בקשה. אין גופן עברי חופשי שכולל גם טעמים
  וגם מראה מודרני, וההכרעה הייתה לוותר על הטעמים ולא על הגופן.
- **הניקוד הושלם** בקטע חגיגה ובחלקי התפילה שנמסרו בלעדיו.
- **שמות הקודש בכינוי** — ה׳, אֵ־ל, אֱ־לֹהַי, יָ־הּ. הדף נועד להדפסה ולתלייה,
  ובסופו של דבר להישלך.
- הדגשות בצבע בלבד. כל רקע או קו תחתון היה מתנגש בניקוד.
- מצב לילה, שלוש מדרגות גופן (נשמרות ב-`localStorage`), הדפסה לדף A4 אחד.
- שם החולה ב-`sessionStorage` בלבד. אין אנליטיקס, אין קוקיז, אין שירות חיצוני.
